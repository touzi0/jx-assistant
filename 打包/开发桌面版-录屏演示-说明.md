# 开发桌面版·录屏演示（AI数字助理.exe，不被安装包杀掉的开发实例）

为「录制安装版安装过程 + 充值使用演示」准备：开发实例以 **AI数字助理.exe** 之名
运行在独立目录，录屏中途跑安装包（覆盖安装）**不会**把它关掉——安装包
（`打包\安装包.iss` 的 `TaskKillApp`）用 `taskkill /IM <镜像名> /F` 精确匹配
**镜像名**杀进程（不看路径），当前名单只有：

| 安装包要杀的 | 来源 |
|---|---|
| `坚祥数字助理GO.exe` | `{#MyAppExeName}`（当前正式名）+ exe 名切换期的迁移段（无条件） |
| `MD查看器.exe` | 查看器托盘驻留 |

`AI数字助理.exe` 不在名单里 → 机制上必然存活（2026-11-13 实测证据见文末）。

## ★ 撞名预警（exe 名切换期必读）

正式版按《exe名切换-AI数字助理-一周后操作清单.md》改名 `AI数字助理.exe` 后，
正式安装包的 taskkill 名单将**包含 AI数字助理.exe**——本开发版会被安装包杀掉。
届时（且仅届时）把 `打包\开发桌面版-录屏演示.ps1` 里的 `$ExeName` 改成
`'AI数字助理-开发.exe'`（仅此一处；配置名/互斥体/联接随之有效），两个入口
`.bat` 一并改名即可。

## 两种数据模式

### isolated（默认，安全）——录制「充值使用演示」用它

- 数据落 `dev-app\data`、`dev-app\工作区`，互斥体 `JX-Desktop-DevApp-Isolated`、
  随机高位端口——**与正式版可同时开**，互不相干。
- 首启自动沿用仓库根 `config.json` 的模型通道（复制后只校正 dataDir/workspace/
  skillsDir 三个路径字段）；**远程中继自动关闭**（config 复制来的设备号与宿主
  相同，同号注册会被网关互踢、手机入口闪断，故隔离实例必须关）。
- 公司同步照常：服务端账号的会话会同步下来，界面里有历史会话可展示。

### shared（演示用户真实数据）——录「已有会话/充值状态」用它

- `dataDir`/`workspace`/`skillsDir` 指向**正式安装目录**（注册表 AppId
  `{BE7768E7-…}` 的 InstallLocation 自动探测，本机为 `D:\123\坚祥数字助理GO\`），
  界面读到的就是正式版的真实会话与数据。
- **风险与安全口径（务必照做）**：两个进程同写一个 `jx.db`（SQLite）会冲突。
  脚本启动前检查「正式目录下的主程序进程」，在跑即**拒绝启动**并在日志写明
  原因——请先**完全退出正式版（含托盘）**再双击共享入口。config 是现场生成的
  副本（正式配置的相对 `dataDir` 会锚到 dev-app，必须绝对化），**绝不回写正式
  配置**。互斥体用 `JX-Desktop-DevApp-Shared`：单写者靠启动拦截保证。
- 远程中继保持开启：正式版退出后由共享实例接管同一设备号，手机入口不断。

## Windows 计划任务启动（无交互会话）

脚本已按计划任务场景打磨：路径全绝对、无任何交互提示、日志全落文件、
go 工具链走绝对路径（`D:\智能体工作区\toolchain\go\bin\go.exe`）、
编译前 Push-Location 到仓库根（任务的 cwd 是 System32，不锚定会报
`go.mod file not found`）、失败退出码 1（任务的「上次结果」可见）。

可复制的创建命令（一次性任务示例，其他触发方式换 `/SC` 参数即可）：

```
schtasks /Create /F /TN "AI数字助理-开发版-录屏-隔离" /SC ONCE /SD 2026/11/14 /ST 09:30 /TR "powershell.exe -NoProfile -ExecutionPolicy Bypass -File \"D:\智能体工作区\软著版数字助理\打包\开发桌面版-录屏演示.ps1\" -DataMode isolated"
```

- **运行账号**：如上不指定 `/RU`，任务以当前登录用户的交互令牌运行
  （「只在用户登录时运行」）——桌面窗口可见、录屏能拍到，**推荐**。
- 手动触发：`schtasks /Run /TN "AI数字助理-开发版-录屏-隔离"`；
  查看结果：`schtasks /Query /TN "AI数字助理-开发版-录屏-隔离" /V /FO LIST`。
- 不要加 `/RU` 存凭据做后台运行：无交互会话里窗口不可见，不适合录屏场景。
- 共享模式任务把 `-DataMode isolated` 换成 `-DataMode shared` 即可。
- 本机已建好两个任务可直接用：`AI数字助理-开发版-录屏-隔离`、
  `AI数字助理-开发版-录屏-共享`（注意共享任务建的是 `-NoBuild` 快捷形态，
  改完整形态删掉该参数重建即可）。

**关于「真跑一次完整安装包」**：本机当前 AI 会话宿主本身就是
`坚祥数字助理GO.exe` 进程（仓库根开发产物），真跑旧名安装包的
`taskkill /IM 坚祥数字助理GO.exe /F` 会把它连带杀掉（taskkill 不看路径），
与任务「不杀主进程」纪律冲突——故按任务书授权采用上表 3/4/5 的最小化验证。
**录屏当天由用户真跑安装包时，开发版存活即是最终确认**（机制与名单双重保证）。

## 录屏当天建议流程

1. `schtasks /Run /TN "AI数字助理-开发版-录屏-隔离"`（或双击 bat）起开发版，
   确认窗口正常、能对话。
2. 开始录屏：先演示功能（充值流程用共享模式前先退出正式版）。
3. 跑安装包（正常走安装向导，录屏拍全程）：观察开发版窗口全程不被关闭；
   任务栏里的正式版实例（若在跑）被关闭并升级替换。
4. 安装完成后再演示新装正式版的首次使用。

## 故障排查

- 进程起不来：看 `dev-app\logs\启动-*.log`（脚本层，含互斥体/端口/拒绝原因）
  与 `dev-app\data\desktop.log`（程序层，GUI 版日志固定落这里）。
- `go.mod file not found`：脚本版本过旧（未 Push-Location），用当前版本。
- 共享模式被拒：按日志提示先完全退出正式版（托盘里也要退）再试。
- 想彻底重来：删 `dev-app\data`、`dev-app\工作区`、`config-隔离.json` 后再启动。
