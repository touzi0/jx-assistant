# 右栏「文件」视图的编辑模式（编辑 / 保存 / 取消 + 写文件接口）

> 2026-11-16 · 后端新增 `fileedit.go` + 前端 `web/` 三文件 · 构建：`go build`（前端经 go:embed 内嵌）

## 一、做了什么

用户不必再开记事本：右栏「文件」页签顶栏加一个**编辑**按钮 →

- 进入编辑模式后，编辑区显示的是该文件的**当前完整内容**（不是 diff，不是历史版本对比），等宽字体、大文件可滚动；
- 底部两个动作：**保存** / **取消**；取消＝回只读视图、文件一点不动；保存＝写回磁盘并自动把旧内容留成历史版本；
- 保存中按钮禁用（防连点）；保存成功回只读视图并刷新 diff，顶部绿字「已保存（旧内容已存为该文件的历史版本，可在「历史版本」里回退）：<路径>」；
- 编辑中顶栏的「打开 / ⟳ 重新读取」置灰（避免编辑器里的稿子与外部程序互相覆盖），「折行」仍可用于编辑区；
- 快捷键：`Ctrl/Cmd+S` 保存、`Esc` 取消。

顺带修了一处旧文案：这个顶栏按钮原先叫「打开方式」，改回**打开**（浏览器页签那个「打开方式」不动，那里确实是"选一个方式打开网页"）。

## 二、接口契约

两条新路由（`server.go` 的 `registerRoutes`，实现见 `fileedit.go`），用 `mux.HandleFunc` 直接挂、**不进 `apiRoute`/call_api 目录**：这是用户在界面上的手势（与 `open-path`、`delivery/open` 同类），写文件的能力必须留在人手——进了 call_api 目录，长期助理（总控刻意不配写工具）就能绕道拿到写入口。

### GET `/api/sessions/{id}/file?path=<工作区相对路径>`

取文件**当前全文** + 保存时要带回来的版本标识。编辑器打开时调。

| 情形 | 码 | 响应 |
|---|---|---|
| 成功 | 200 | `{path, text, size, mtime, hash, encoding, lineEndings, maxBytes}` |
| 缺 path | 400 | `{"error":"需要 path"}` |
| 越出工作区 | 400 | `只能编辑本会话工作区内的文件：<原样> 落在工作区之外` |
| 指向 .jxai | 400 | `这是助手的内部数据（.jxai 系统目录：快照正文 / 暂存 / 交付备份），不能在右栏编辑` |
| 是文件夹 | 400 | `这是一个文件夹，不能当文件编辑` |
| 超 2MB | 400 | `文件太大（2.0 MB），右栏编辑器只支持 2MB 以内的文本文件——用顶栏「打开」交给系统程序` |
| 二进制 | 400 | `这是二进制文件（1.0 KB），右栏编辑器只能打开文本文件——用顶栏「打开」交给系统程序` |
| 编码识别不了 | 400 | `这个文件的编码识别不了（既不是 UTF-8，也不是 GBK / UTF-16 文本）…` |
| 不存在 | 404 | `文件不存在（可能已被删除或改名）` |
| 读不到（被独占 / 无权限） | 400 | `读不到这个文件：它正被其他程序独占打开（记事本 / Office 等）…` / `…没有读取权限` |

`text` 是解码后的文本（BOM 已剥离、正文按原编码还原）；`encoding` 是 `UTF-8` / `UTF-8(BOM)` / `GBK` / `UTF-16LE` 之类；`lineEndings` 是 `lf` / `crlf`（主导风格，保存时据此还原）；`hash` 是内容的 sha256；`mtime` 是毫秒时间戳（远程工作区为 0）。

### POST `/api/sessions/{id}/file`

```json
{ "path": "demo.txt", "content": "全文…", "hash": "<打开时的 sha256>", "mtime": 17633…, "lineEndings": "crlf" }
```

`hash` 与 `mtime` 至少要给一个（`hash` 优先）：这是冲突校验的基线，也是"绝不静默覆盖"的执行点。

| 情形 | 码 | 响应 |
|---|---|---|
| 成功 | 200 | `{ok:"1", path, size, mtime, hash, encoding, lineEndings, snapshotId, versioned}` |
| 请求体不是 JSON / 缺 path | 400 | 中文原因 |
| 缺版本标识 | 400 | `需要 hash 或 mtime：保存必须带上打开编辑器时读到的版本标识…` |
| 磁盘内容与 hash 不一致 | 409 | `文件已被其他程序修改过（内容与打开编辑时读到的不一致），没有覆盖——点「取消」再重新打开编辑即可看到最新内容` |
| 磁盘 mtime 不一致（只有 mtime 时） | 409 | `文件已被其他程序修改过（修改时间与打开编辑时不一致）…` |
| 文件已被删掉/改名 | 409 | `文件已经被删除或改名了（不是这里改的），没有写回——重开编辑可看到最新状态` |
| 磁盘上已不是可编辑文本 | 400 | `磁盘上这个文件已经不是可编辑的文本了（编码识别不了），拒绝按文本覆盖…` |
| 内容 > 2MB | 400 | `内容太大（3.1 MB），右栏编辑器只支持保存 2MB 以内的文本` |
| 目标编码表示不了新内容 | 400 | `<编码> 表示不了这些字符（文件未改动）` |
| 写失败：只读 / 被占用 / 磁盘满 | 500 | `写入被拒绝：目标目录或文件是只读的（只读目录或微信接收目录默认只读…），也可能是文件正被其他程序占用…` / `文件正被其他程序占用…` / `磁盘空间不足，没有写入。` |

`snapshotId` 是写前落的快照 id（0 = 没留快照，例如文件在 `.jxai` 系统目录或备份开关关闭）。

### 写前快照（复用既有 file-versions 机制）

`snapshot.go` 里把"写前基线采集"和"落快照"抽成两条公共函数 `snapshotBase` / `recordCheckpoint`，模型的 write/edit（`snapshotWrite`）与右栏手工编辑（`fileedit.go` 的 `panelWriteFile`）共用同一口径：

- 快照记 `tool_name = file_edit`、`seq = 0`：只进该文件的「历史版本」列表（可「查看内容 / 恢复到此版本前」），**不锚定任何对话回合**，因此不会被「按轮撤回 / 全部撤回」顺带带走；
- 正文照常写进 `.jxai/snapshots/`，改动前内容随快照保存（`hasBody=true`）。

## 三、护栏与安全

| 项 | 做法 |
|---|---|
| 目录穿越 | `panelEditTarget` 用 `resolve` + `filepath.EvalSymlinks`（本地）解析到真实路径，再用 `displayPath` 判是否仍在工作区内（`withinWorkspace`：拒绝 `..`、绝对路径、盘符），越界一律 400，不落盘 |
| 系统目录 | `.jxai`（快照正文 / 暂存 / 交付备份）拒绝编辑——改坏了回退能力就没了 |
| 只收文本 | 读写两侧都过 `detectTextEncoding`：二进制 / 识别不出编码都拒绝，**不猜** |
| 编码与行尾 | 按原编码写回（GBK 文件仍是 GBK、UTF-8(BOM) 仍有 BOM）；`lineEndings=crlf` 时把 textarea 的 LF 还原成 CRLF（否则"用右栏改一下"会悄悄把 `.bat/.cmd` 的行尾全改掉） |
| 大小 | 单文件 2MB（读、写两侧都卡） |
| 冲突 | 客户端必须回带打开时读到的 `hash`（或 `mtime`），与磁盘当前不一致 → 409，绝不覆盖 |
| 写失败提示 | `panelWriteError` 把 `Access is denied` 翻成"只读目录（微信接收目录默认只读）/ 文件只读 / 正被占用"，把 sharing violation 翻成"被其他程序占用" |

视觉口径：

- 编辑区字号不写死 px——外层 `font-size: var(--chat-fs)`（设置里「字体大小」的同一基准），textarea 内部 `.93em`、行高 1.6，改设置时随整个右栏一起变；
- 等宽 `Consolas, "Courier New", monospace`，背景取 `--code-bg`、文字取 `--text`，亮/暗两套主题都从变量派生；
- 按钮沿用 `fvw-ico` / `fvw-btn` 现有风格，「保存」用主题强调色。

交互细节：

- 保存中：保存/取消按钮与编辑区一起禁用，按钮文案「保存中…」，回来后复位；
- 保存失败（尤其 409）：红底提示条说明原因，**编辑区内容保留**，底栏提示「没有写回：磁盘上的文件已经变了（内容仍在编辑区，可复制备查）」；
- 取消：有改动先弹「放弃对「x」的修改？文件保持原样，改过的内容不会保存」，确认才回只读；
- `Esc` 的处理**就地 `stopPropagation`**：document 上那条全局 Esc 处理器会关"正在打开的确认框"，而我们的确认框正是在这次按键里同步打开的，不拦住就会被立刻关掉（实测踩到过）。

## 七、已知取舍

- **只收文本、单文件 2MB**：二进制与超大文件请在外部程序里改（顶栏「打开」）。
- **保存是整文件重写**：不做行级合并；与外部修改撞车时一律 409 让用户重新打开，不猜。
- **切会话会丢草稿**：切换文件会先确认，切会话/收起页签直接丢弃（切会话是明确的导航动作，弹确认反而碍事）。
- **远程工作区**：SFTP 拿不到 mtime，冲突校验只能走 hash（读侧总会下发 hash，正常不影响）。
- 主进程未被替换：本次产物为 `D:\智能体工作区\数字助理GO\坚祥数字助理GO-右栏编辑器-20261116.exe`，用户自行替换重启才会生效（rebuild-engine.ps1 那套流程照旧）。
